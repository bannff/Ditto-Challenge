# Safe-change skill

This package supports the Implement stage. It keeps the implementation swarm focused on the smallest change that satisfies the approved plan while it works through the already-enforced isolated-worktree tools.

`SKILL.md` emphasizes scoped edits, appropriate test changes, policy and lesson recall, and an honest summary of the edits. It does not authorize claims that the tests passed; the platform’s acceptance gate remains authoritative.
