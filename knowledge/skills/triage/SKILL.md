# Triage

- Read before you plan: open the actual code the ticket points at with the file tools and
  cite concrete files and symbols. Never guess at code you haven't read.
- Consult the policy tool for security rules, and recall past lessons, before you decide.
- Classify as **bug**, **feature**, or **refuse**. Refuse anything unsafe, out of scope for
  this repo, or too underspecified to act on — and state the reason.
- End with a short, concrete plan a coder can follow: the files to change and the acceptance
  signal that will prove it worked.
