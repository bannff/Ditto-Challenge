# Lesson writing

- Recall existing lessons first; don't repeat one that's already stored.
- Write exactly ONE lesson: on success, the pattern that worked; on failure, what went wrong
  and how to avoid it next time.
- Make it durable and generalizable — an actionable rule, not ticket-specific trivia.
- Keep it junk-resistant: no secrets, no absolute paths, no run-specific IDs. Output only the
  lesson.
