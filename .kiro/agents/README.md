# Kiro specialist agents

These files define the specialist roles Kiro can use while working on autodev. They turn the project’s review expectations into reusable roles with scoped tools, permissions, and source material.

- `build-lead.md` coordinates work and delegates specialist questions.
- `meta-architect.md` gates architecture and scope before implementation.
- `strands-expert.md` verifies Strands, Bedrock, plugin, and evaluation usage.
- `implementer.md` writes focused application changes.
- `qa-tester.md` tests the safety boundary, test gate, budgets, refusal, and learning behavior.
- `security-engineer.md` reviews trust-boundary escapes, injection, secret exposure, and sandbox failures.

Equivalent portable role descriptions live in `.agents/`; these definitions add Kiro-specific tool permissions and resources.
